# Methodology

## Evidence classes

| Class | Meaning |
|---|---|
| observed | Directly inspected in an artefact |
| documented | Explicitly stated by an identifiable source |
| inferred | Reasoned interpretation supported by evidence |
| assumed | Temporary hypothesis introduced to progress a model |
| unknown | Not established by available evidence |
| disputed | Sources conflict or interpretation is unresolved |

Every material property should point to evidence records with stable IDs, source URL, publisher/author, publication and retrieval dates, locator (page, figure, paragraph or image), rights note and extraction method.

## Uncertainty

Record affected entity/property, hypothesis, alternatives, impact if wrong, confidence rationale, validation action, owner and status.

## Validation ladder

1. Source integrity.
2. Semantic integrity.
3. Geometric plausibility.
4. Functional plausibility.
5. Physical validation against a sample or authoritative CAD.
6. Production validation of materials, tolerances, safety, compliance and manufacturability.

A successful render is not engineering validation.
