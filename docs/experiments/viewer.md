# Interactive 3D assembly viewer

1. Open the [Sand3D smoke-test workflow](https://github.com/andiekobbietks/product-engineering-lab/actions/workflows/cad-smoke.yml) and download the latest successful artifact named `gb2591502a-hair-applicator-research-proxy`, or run the [Colab notebook](https://github.com/andiekobbietks/product-engineering-lab/blob/main/experiments/001-nyfasi-reconstruction/notebooks/nyfasi_reconstruction_colab.ipynb).
2. Extract the artifact ZIP and locate `gb2591502a_hair_applicator_research_exploded.glb`.
3. Open the [local GLB viewer](glb-viewer.html) and select the file.

The viewer uses Google's model-viewer component from its public CDN. It runs in a modern browser with internet access. It does not perform dimensional or mechanical validation.
